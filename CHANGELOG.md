# Changelog

## [1.0.0] - 2026-08-16

### ✨ Primeira release pública

A primeira versão do Build Roulette foi lançada com foco em ideação rápida e fluxo de uso simples.

#### Funcionalidades incluídas
- Geração aleatória de ideias de produtos e serviços para desenvolvedores, founders e criadores
- Combinações automáticas entre tipo de produto, nicho e diferencial
- Botão para girar e gerar uma nova ideia
- Copiar a ideia para a área de transferência
- Salvar ideias em favoritos
- Histórico local das últimas ideias
- Compartilhamento via Web Share API ou cópia
- Modo de rotação automática
- Suporte para teclado: barra de espaço para girar rapidamente
- Persistência em localStorage para manter estado entre recarregamentos

#### Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

#### Verificação
- Build de produção validada com sucesso via `npm run build`
- Resultado: compilação Next.js concluída sem erros

#### Observações
- A aplicação é totalmente client-side
- Não há backend ou banco de dados na primeira release
- O objetivo desta versão é servir como ferramenta leve de brainstorming e inspiração
